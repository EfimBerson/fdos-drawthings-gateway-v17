# FDOS Draw Things Gateway v1.7 — только локальный Draw Things CLI

**Задача:** один OpenAI-совместимый провайдер Cherry Studio на `http://127.0.0.1:7777/v1`. В v1.7 **не требуется DHTServer и порт 7766**. Обнаружение моделей, генерация, редактирование и работа с референсами идут исключительно через установленный `draw-things-cli`.

## Запуск на macOS

1. Убедись, что работает `draw-things-cli models list --downloaded-only`.
2. Останови предыдущий Gateway (Control+C). **Не удаляй v1.6** — это проверенная резервная копия.
3. Распакуй папку `fdos-drawthings-gateway-v1.7` в `~/Apps/`.
4. Запусти:

   ```bash
   cd ~/Apps/fdos-drawthings-gateway-v1.7
   /usr/bin/python3 gateway.py
   ```

5. Проверь:

   ```bash
   curl -s http://127.0.0.1:7777/health | python3 -m json.tool
   curl -s http://127.0.0.1:7777/v1/models | python3 -m json.tool
   ```

6. В Cherry Studio сохрани существующий провайдер `http://127.0.0.1:7777/v1`, нажми **Sync Models**. При необходимости удаляй устаревшие имена только в интерфейсе Cherry.

### Модели и настройки

- Список скачанных моделей: `draw-things-cli models list --downloaded-only` (кэш 10 секунд).
- LTX/видеомодели **не предлагаются** как Image Generation.
- Каждая модель изображений получает три профиля `1K`, `2K`, `4K` и отдельные профили `Edit / References` и `Chat image`, совместимые по идентификаторам с v1.6.
- Выбор пропорций через **существующее меню Cherry**: `1024x1024` → 1:1, `1536x1024` → 16:9, `1024x1536` → 9:16. Например, 2K + 16:9 означает 2048×1152.
- Сохраняется реальный размер 4K; доступность зависит от модели и памяти Mac.
- Все PNG и JSON сохраняются в `~/Pictures/FDOS-DrawThings`.

### Редактирование и референсы

`POST /v1/images/edits` принимает OpenAI-совместимый multipart и JSON. До 10 изображений, первое — основной холст, остальные — moodboard. Файлы хранятся во временном каталоге на время CLI-запуска, затем удаляются. Если выбранные пропорции не совпадают с первым изображением, включается `--crop`, чтобы сохранить его как холст. Важное следствие: изображение может быть обрезано по центру.

Весь CLI-запуск использует `--local --offline --no-download-missing` — **без скачивания моделей и без облачного запуска**. Таймаут каждой генерации 900 секунд; если Cherry прекращает ожидание раньше, файл может сохраниться, но не отобразиться в редакторе.

### Обычный чат

Сохранены экспериментальные Chat-профили с `fdos-chat--...`. Встроенный рендер изображений и передача изображений Chat через Cherry 2.1.10 не подтверждены живым тестом. Для гарантированного результата используй Painting.

### Диагностика

- `GET /health`: CLI найден и каталог прочитан.
- `[cli] model=... refs=0`: генерация с нуля.
- `[edit:...] CLI_START ... refs=3`: три входных фотографии распознаны.
- `[saved]`: PNG записан.
- `HTTP 200`: результат успешно отправлен.
- `503`: CLI отсутствует или список моделей недоступен.
- `502`: локальный CLI завершился с ошибкой/таймаутом.

### Встроенные тесты

```bash
/usr/bin/python3 test_v17.py
```

Это тесты с имитацией CLI; они не заменяют реальные тесты Z Image, Krea, Qwen и FLUX на Mac.

### Существующие ограничения

- Отдельный видео-генератор LTX не интегрируется.
- Формат таблицы списка моделей CLI парсится как текст. Если Draw Things изменит формат вывода, `/health` покажет ошибку вместо молчаливого объявления неправильных моделей.
- Для некоторых моделей режим редактирования может не поддерживаться движком, хотя общий CLI принимает `--image`; это нужно проверять на конкретной модели.
- Не нужно запускать DHTServer или изменять конфигурацию Cherry Studio ради переключения между DHT/CLI — такого переключения в v1.7 нет.
